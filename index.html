Overview

This project builds a full Discounted Cash Flow model to estimate the intrinsic value of Wingstop Inc. (WING) using publicly available financial data. The model projects free cash flows over a multi-year forecast horizon, discounts them at the weighted average cost of capital, and adds a terminal value — producing an estimated fair value per share.

The analysis examines Wingstop's unit economics, franchise model, and growth trajectory to inform the assumptions driving the valuation. Sensitivity analysis tests the model's output across ranges of growth and discount rate assumptions.
